# Labeling rules (Module 9)

`labels.csv` is generated by `training/build_labels.py` from Roboflow COCO exports. All sources are CC BY 4.0; attribution is in the `source` column.

## Sources used
| key | dataset | what we take |
|---|---|---|
| hail | deldetect/roof-shingle-hail-damage | any hail box -> `hail`, `roof_shingles` |
| wind | deldetect/roof-wind-damage | any box -> `wind`, `roof_shingles` |
| house_damage | house-damages/house-damage-boxes | filename prefix -> `fire` / `water` / `none`, `component=other` (max 60 per type) |
| intact_roof | hand-collected web photos (25) | `none / none / roof_shingles`; license unverified, keep private. At least one is a flat membrane roof, not shingles |

Not used: `keyan/roof-damage-detection` (only a generic "damage" class, so hail vs wind is unknowable).

## Rules
- **One image per original photo.** Roboflow exports repeat photos (`name.rf.<hash>.jpg`); we keep the variant with the most boxes. The part before `.rf.` is the `group`, and a group never crosses train / val / golden.
- **No boxes != undamaged.** Images with no boxes are skipped, never labeled `none`.
- **Severity is a heuristic for roof data (weak label):**
  - hail: <= 2 boxes minor, <= 8 moderate, more severe (boxes are tiny, so count them)
  - wind: boxes cover < 6% of the image minor, < 16% moderate, else severe (boxes are large, so use area)
- **house_damage severity** comes from the dataset's own box colour: Green = minor, Amber = moderate, Red = severe; `NoDamage` = none.
- **Skipped prefixes:** NaturalDamage, Mold, Cracks, Collapses (do not map cleanly to the schema).
- **Synthetic `poor` images** (added by `prepare_dataset.py`): blurred, darkened or shrunk copies of real images. Target = `unclear / unclear / unclear / poor`. They stay in the same split as their source photo.

## Known limits
- Only 25 intact-roof (`none` on `roof_shingles`) images; the other 60 `none` examples are interiors, so "room = none" is still a risk.
- fire / water / none images look synthetic; do not expect the same scores on real photos.
- Roof severity cannot be validated against any ground truth.
