# ClaimGuard vision model

Fine-tuned Qwen3-VL-2B (LoRA). One photo in, a JSON description of visible damage out.
It describes what is visible. It does not decide coverage.

Settings (Space variables / secrets): `ADAPTER_REPO` (Hugging Face id of the adapter), optional `HF_TOKEN`
(secret, for a private adapter repo). See `inference.py` for the rest.

This folder is generated by `scripts/build_space.py` in the ClaimGuard repository. Edit the source there.
